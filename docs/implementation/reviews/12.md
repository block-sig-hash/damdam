## Findings and fixes

1. **P1 — merchant routing ignored payment method.** Explicit
   `merchant_payment_methods` now gates each rail. No match, no live match and
   multiple matches are distinct fail-closed outcomes.

2. **P1 — an intent could connect an order to another seller or amount.** Intent
   creation now locks and validates the order, seller, merchant, currency,
   amount and optional quote. A composite foreign key binds merchant/seller/
   currency in PostgreSQL, and an immutability trigger freezes the intent.

3. **P1 — attempts could race or reuse an idempotency key.** Processor/key is
   unique, only one created/pending/unknown attempt can be live, and attempt
   creation locks the intent. Generated keys now use the character set Paystack
   documents rather than the submitted colon-separated value it rejects.

4. **P1 — two distinct captures could lose the second payment.** Capture now
   serializes on the intent. The winner marks the order paid; a different late
   success records an `ExcessPayment` instead of failing and rolling back after
   the processor already moved money.

5. **P1 — late failure could downgrade success.** Succeeded attempts are
   idempotent and immutable in PostgreSQL. Unrecognized non-success statuses
   become unknown rather than definitive failure.

6. **P1 — excess records retained arbitrary provider payloads.** Stored
   evidence is now allowlisted payment facts; customer and authorization/card
   objects are discarded.

7. **P1 — the Paystack request omitted required email and used the wrong wire
   shapes.** Checkout now requires payer email, sends the minor-unit amount as
   the documented string, JSON-encodes metadata, validates the API envelope and
   rejects malformed response facts instead of defaulting currency to NGN.

These Paystack checks were compared with the current official
[Transaction API](https://paystack.com/docs/api/transaction/) and
[webhook verification](https://paystack.com/docs/payments/webhooks/)
documentation on 10 September 2026. That is contract evidence, not a live call.
