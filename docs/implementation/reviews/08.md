## Findings and fixes

1. **P1 — mobile action controls were hidden from assistive technology.**
   `StateMessage` and `PartialFailureNotice` made their entire root an
   accessible element, which collapsed nested buttons into the parent summary.
   Each component now exposes a separate summary element and keeps its action
   as an independent accessible control.

2. **P1 — the required visual evidence did not exist.** The submitted handoff
   explicitly left the screenshot criterion unmet. CI now renders and validates
   eight dashboard captures across English, French, 320/768/1280-pixel widths
   and 200% text. The Android job produced the complete derived matrix: 13
   successful Maestro flows and 26 nonempty PNGs.

3. **P1 — the first large-text browser implementation clipped horizontally.**
   Visual review caught the failure at a 320-pixel viewport. Large-text evidence
   now doubles the typography tokens while allowing normal layout reflow. The
   capture script measures every rendered element and rejects horizontal
   overflow before accepting an artifact.

4. **P2 — an unknown usage reading could still imply consumption.** Passing a
   stale nonzero fraction with no update time painted a usage value the carrier
   had never reported. Both apps now render the unknown state as an empty neutral
   meter and omit an invented percentage from the accessibility label.

5. **P2 — invalid call-payer and price states were representable.** A work-paid
   call could omit its organization, and a whitespace-only price still enabled
   the action. `CallPayer` is now a discriminated union requiring the
   organization for work calls, and blank price text disables calling.

6. **P2 — dashboard CSS referenced token names that the generator never
   declared.** Heading and body variables used names such as
   `--type-heading1-size` while generation emits `--type-heading-1-size`.
   References were corrected and a test now proves every CSS `var()` has a
   declaration.

7. **P2 — the dashboard gallery was public in every production build.** The
   route now returns 404 unless `DESIGN_GALLERY_ENABLED=true`. Production-build
   checks prove the disabled and enabled behavior, including French negotiation.

8. **P2 — two Android evidence targets were below the harness picker fold.**
   The earlier CI artifact omitted activation prompt and success captures even
   though their views existed. The flows now scroll until the target is visible;
   the corrected run contains both locales for both screens.

9. **P1 — clean Android runners could not reliably resolve native buildscript
   dependencies.** `react-native-localize` 3.7.0's buildscript omits Maven
   Central, although the Android Gradle Plugin it loads has transitive artifacts
   there. One exact-head run failed after searching only Google and the Plugin
   Portal. The root project now adds Maven Central to every native subproject's
   buildscript repositories before evaluation, without editing `node_modules`.

10. **P3 — locale state leaked between component tests, and French empty-state
   agreement was wrong.** Tests reset locale deterministically, and
   `Personne n'a encore été ajoutée` is corrected in both applications.
