## Findings and fixes

1. **P1 — activation-key rotation broke existing idempotency and open grants.**
   Existing credential and grant fingerprints were looked up only under the new
   key. Fingerprints now use the row's named key, redemption checks every known
   key reference, and a PostgreSQL regression proves a deploy between grant
   issue and redemption does not strand the profile.

2. **P1 — root logger redaction did not cover descendant records.** Python
   logger filters are not inherited. Configuration now protects every existing
   root handler, including third-party capture/shipping handlers, and recursively
   redacts mappings inside lists and tuples.

3. **P1 — foreign formatters could append an unsafe exception traceback.** The
   filter now materializes a redacted traceback/stack before clearing the unsafe
   source, and the JSON formatter preserves that sanitized exception. Tests use
   an otherwise unmodified library logger and foreign handler.

4. **P1 — default read-only privileges exposed future sensitive tables.** The
   automatic future-table grant was removed. Newly migrated tables fail closed
   until the reviewed role script is rerun; activation credentials are then
   explicitly revoked.

5. **P1 — adopting database roles on an existing environment left Alembic
   unable to alter old objects.** The script now transfers public tables,
   table-owned and standalone sequences, views, materialized views, enums and
   domains to `damdam_migrate`. A disposable PostgreSQL database proved both
   ownership adoption and the app/read-only privilege boundaries.

6. **P2 — key-reference parsing accepted ambiguous configuration.** Retired
   references now reject duplicates, empty/whitespace names and characters
   outside the documented safe set; current references follow the same rule.

7. **P2 — worker documentation overstated exactly-once behavior.** Late
   acknowledgement prevents silent work loss, but notification providers still
   have a crash window after accepting a message and before the local sent
   marker commits. The code and handoff now state the at-least-once contract and
   leave provider idempotency/durable dispatch receipts explicit.
