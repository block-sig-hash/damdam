## Findings and fixes

1. **P1 — provisional settlement released the authorization before supplier
   reconciliation.** A higher CDR correction then posted directly against the
   payer, even if later calls had reserved the available balance, and could
   exceed the original maximum. Provisional charges now retain the unused hold;
   positive corrections settle only their difference from it; finalization and
   lower corrections release the remainder; and late or excessive increases
   are capped and queued as DamDam exposure.

2. **P1 — deadline claims did not survive an actual worker crash.** The worker
   committed `claimed` before processing, but only an exception handler changed
   it back to `pending`; a killed process therefore stranded the row forever.
   Claims now carry a five-minute lease and stale claimed rows are atomically
   reclaimable through the same `FOR UPDATE SKIP LOCKED` query.

3. **P1 — renewal enforcement had no production caller or termination path.**
   No renewal deadline was written when provider work started, a stop decision
   merely completed the deadline, and no provider hangup followed. Starting a
   destination leg now checks policy, extends only the reservation expiry lease,
   and writes the first durable deadline. The worker renews and reschedules when
   permitted; otherwise it records stop intent and dispatches one durable hangup
   operation per live leg.

4. **P1 — organization controls remained disconnected after chunk 20 merged.**
   V03 was based on an unreviewed V02 branch and still assumed chunk 20 was
   absent. The API and deadline worker now share the accepted control model, so
   recorded organization caps participate in call renewal decisions.

5. **P1 — a lost destination command could be settled as a free unanswered
   call.** An `UNKNOWN` attempt with no correlated destination leg flowed through
   the empty-leg result and produced a zero charge. It now retains the hold,
   raises `call_unknown_outcome`, and schedules durable reconciliation.

6. **P1 — stored billing time could come from the client leg.** Metering used
   the destination duration but the charge and journal timestamp selected the
   first completed leg, often the client. The stored interval now explicitly
   selects the destination leg, matching the amount and provider evidence.

7. **P1 — supplier-cost replay accepted conflicting facts.** Reusing a provider
   reference with a different amount, currency, leg, attempt or duration silently
   returned the first row. Replays now converge only when those facts match;
   conflicts fail with a named error, and a supplied leg must belong to the
   supplied attempt.

8. **P2 — missing supplier evidence became invisible when its timer elapsed.**
   The worker finalized an event-derived charge without recording that no CDR
   arrived. It now finalizes to close the books and release the hold while leaving
   a `settlement_mismatch` item in the shared exception queue. A supplier record
   counts as CDR evidence only when it carries billable seconds.

9. **P2 — finalization could race a correction.** Supplier-window finalization
   did not take the settlement advisory lock and could release the hold while a
   correction used it. Settlement, correction and finalization now serialize on
   the same attempt key and refresh locked database state before acting.
