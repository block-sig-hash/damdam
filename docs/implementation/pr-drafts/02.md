## What this changes

Repairs refresh-token validation when tests use an application clock different
from real time, and extends consistent date validation to organization tokens.
Concurrent refresh attempts now lock the persisted row so only one can issue a
replacement pair. Expiry, signature, audience and stored revocation checks remain.

Replaces screenshot-count assertions with flow-derived exact coverage and decoded
PNG/CRC validation. Parses Maestro YAML and rejects unsupported dynamic/nested
captures explicitly. Adds a bounded iOS driver-startup timeout, docs-link CI and
an explicit supplemental-only boundary for automated Claude review.
